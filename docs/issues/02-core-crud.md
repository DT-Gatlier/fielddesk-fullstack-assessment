## What to build

Build the Work Orders schema, API endpoints (list, create, update), and the React UI. The UI includes the dashboard shell and a paginated, filterable list using Ant Design.

## Acceptance criteria

- [ ] Work Order DB schema and migrations exist with RLS enabled.
- [ ] API supports CRUD operations with RLS enforced.
- [ ] Dispatcher can view, create, and edit work orders via the UI.
- [ ] UI displays empty, loading, validation, and error states properly.
- [ ] Centralized API error formatting is implemented.
